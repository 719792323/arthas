## 基于 LLM 的 Java 智能诊断系统
### 项目描述：
针对 APM 在 Trace/Metric/Log 发现异常后缺乏深层定位手段的痛点，开发了一套基于 LLM + Arthas 的深度诊断系统。该系统重点解决了自动化诊断在生产环境面临的内网隔离、长链路诊断的稳定性问题（任务中断、上下文溢出）、安全管控以及复杂问题诊断效果不佳等问题，实现了从“现象发现”到“根因定位”的稳定闭环。

#### 1. Arthas MCP Server 改造 
*   **反向代理架构**：设计并实现基于 WebSocket 的反向连接机制，使内网应用无需暴露端口即可被远程管控，解决了生产环境的安全接入问题。
*   **协议标准化**：基于 MCP 标准封装 Arthas 指令，统一了同步/异步指令的调用接口，并对返回数据进行结构化精简，从源头降低 LLM Token 消耗。
*   **无感集成**：将改造后的 Arthas 集成到 Tencent OTel Java Agent ，实现用户接入 APM 后即具备诊断能力，无需人工挂载。

#### 2. 智能诊断平台开发 
*   **自动化诊断引擎**：基于 ReAct 范式构建决策引擎，使 LLM 能够自主制定诊断策略、执行 Arthas 工具并分析结果，实现“CPU 飙高”、“线程死锁”等场景的代码级归因分析。
*   **动态上下文治理**：针对诊断链路长、工具输出大的挑战，设计了**“语义摘要 + 滑动窗口”的多级上下文压缩管道**。通过对 Arthas 返回结果进行即时治理和历史消息的动态剪裁，在保留关键诊断线索的同时，大幅降低 Token 消耗，确保多轮诊断稳定执行。
*   **RAG 知识增强**：构建基于 Parent-Child 双层索引 与 混合检索（Vector+BM25+RRF 融合） 的领域知识库。通过细粒度 Child 检索、Parent Score 聚合的两阶段召回策略，提升了模型对复杂场景的诊断效果。
*   **高可靠状态机与安全审计**：针对 Arthas 诊断命令耗时长、易中断以及安全风险的痛点，构建了基于持久化的事件驱动状态机。实现了诊断任务的异步化调度与全生命周期管理，支持长链路诊断的断点续传、并发控制及高风险指令的人工审核，确保生产环境诊断的稳定性与安全性。

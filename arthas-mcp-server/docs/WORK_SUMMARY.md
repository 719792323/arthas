# Java应用诊断开发
## Arthas MCP Server改造
### 反向代理接入实现
> 基于 WebSocket 实现 Agent 主动外联到管控平台的反向连接架构，支持心跳保活与断线自动重连，使内网应用无需暴露端口即可被远程管控。
### 诊断指令封装优化
> 统一 Arthas 同步/异步指令调用差异，精简指令返回内容、组合封装高阶指令，降低调用复杂度和 LLM Token 消耗
### APM 平台无感知集成
> 将 Arthas 能力嵌入 OpenTelemetry Java Agent，用户接入 APM 平台后即自动具备按需诊断能力，无需额外部署。

## 智能诊断平台开发
### 管控程序开发
> 构建统一诊断管控程序，实现任务生命周期管理、异步流程调度及高风险操作安全约束，支撑生产环境下可控、稳定的诊断流程。
### 诊断程序开发
> 基于 LLM 构建智能诊断程序，将用户问题拆解为多步诊断策略，并结合中间结果动态调整分析路径，实现自动化根因定位与诊断结论生成。
